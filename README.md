# prflab

This is the handout directory for [prflab](https://github.itu.dk/pages/OSC/web25/prflab.html) - the lab that teaches you how to exploit hardware and systems-software to write high-performance software. Make sure to read the URL'ed lab description before you proceed.

For setting up prflab, and submitting your work, please follow the same directions as for [clist](https://github.itu.dk/OSC/clist25) (with URLs suitably modified). For doing the assignment, consult the lab description on the course website.
